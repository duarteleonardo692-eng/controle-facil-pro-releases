# Controle Fácil Pro — Atualizações Windows

Este repositório é reservado exclusivamente à **distribuição de versões e arquivos de atualização** do Controle Fácil Pro para Windows.

## Situação atual

O canal de atualizações está **em configuração**. Ainda não há uma versão comercial publicada aqui. Não baixe arquivos de fontes não verificadas.

## Política de publicação

- O código-fonte do aplicativo permanece em um repositório **privado**, separado deste canal.
- Apenas versões validadas, com testes de migração e assinatura digital verificada, deverão ser publicadas para clientes.
- Cada publicação poderá incluir o instalador `.exe`, o manifesto `latest.yml`, o arquivo `.blockmap`, notas de versão e suas verificações de integridade.
- Nunca serão publicados aqui dados de clientes, senhas, tokens, certificados privados ou bancos de dados.
- As versões de testes internas não são destinadas a clientes.
